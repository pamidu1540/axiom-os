LOCAL DEVELOPER WORKSPACE TOOLKIT

Start with your workspace.

Axiom OS brings project tasks, build plans, snapshots, and background processes into one PowerShell command.

1. Choose a folder

Open Axiom OS from Start. Pick a workspace outside the application folder. Leave starter tasks selected to try a small example without installing a language SDK.

2. Open your terminal

Select Save workspace & open terminal. PowerShell is included. Try:

axiom --help
axiom env check
axiom run hello
axiom ps --json

3. Work with a project

Put a trusted project inside the workspace. Go, Rust, Python, and Node.js are installed separately when needed.

axiom compile my-project linux --dry-run
axiom sandbox create my-project --name experiment
axiom sandbox diff experiment
axiom sandbox destroy experiment

Snapshots copy files. Commands still run with your account's permissions. A snapshot commit merges added and changed files; it does not delete source files.

Keep secrets private

axiom vault set MY_API_KEY
axiom vault exec MY_API_KEY "python client.py"

Secret entry is hidden. Keys are encrypted for your Windows account. Keep credentials out of task command strings and source control.

Updates and uninstall

Run a newer installer to update. Uninstall through Windows Settings; your chosen workspace and local settings are preserved. Stop managed tasks before uninstalling.
